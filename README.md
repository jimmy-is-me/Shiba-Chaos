# 柴犬拆家大作戰：咖呲的惡作劇（Shiba Chaos）

原創 HTML5 Canvas 柴犬動作遊戲，由 WUMETAX Lab 製作。玩家操控柴犬咖呲在家中探索、惡作劇、收集骨頭並躲避主人。遊戲完全在瀏覽器執行，無須登入或後端服務。

- 線上遊戲：https://shiba-chaos.pages.dev/
- 製作者：https://wumetax.com/

## 遊戲模式

### 闖關模式

保留原有計時、狗掌生命、主人 AI 巡邏、關卡目標與星級紀錄，並擴充為五個關卡。通關上一關即可解鎖下一關：

1. **客廳大冒險**：撞翻花瓶、抓沙發或咬拖鞋
2. **廚房偷吃大作戰**：弄倒餐具零食、達成連擊
3. **書房拆家王**：推書、拉窗簾及衛生紙
4. **陽台花園風暴**：撞落花盆、零食罐和花園玩具
5. **洗衣間大暴走**：拉紙巾、扯晾衣簾、推書和收納用品

第一關通關解鎖超級狗掌，第二關通關解鎖二段跳。原本的關卡紀錄和技能解鎖會保留。

### 自由拆家模式

主選單點選「自由拆家模式」即可開始：

- **五個房間相連**，不用依序解鎖；可從客廳一路探索到洗衣間
- **不限時間、沒有遊戲失敗**，被主人抓到只會扣分
- **主人巡邏可開關**：想單純探索就關閉；想玩潛行追逐就開啟
- **持續重生的物品**：破壞後會逐步恢復，適合重複連擊與練習
- **七種循環委託**：惡作劇、找骨頭、撞花瓶、連擊、咬拖鞋、推書及拉紙捲，完成可領取骨頭
- **骨頭收集**：靠近即可拾取，等待一段時間會重新出現
- **自由探索位置保存**：退出或遊玩期間定期記錄，重新進入時可從之前的區域繼續

### 咖呲造型衣櫃

收集骨頭可解鎖並穿戴四種外觀：

| 造型 | 骨頭花費 |
| --- | ---: |
| 經典橘柴 | 免費 |
| 奶油白柴 | 12 |
| 黑柴偵探 | 24 |
| 咖呲隊長（配帽子） | 36 |

造型只是外觀，不會提供付費戰鬥優勢。骨頭、已解鎖造型與已完成委託次數儲存在使用者瀏覽器的 LocalStorage。

## 控制方式

| 操作 | 電腦鍵盤 | 手機觸控 |
| --- | --- | --- |
| 移動 | A / D 或左右方向鍵 | 左右移動按鈕 |
| 跳躍／二段跳 | W / 空白鍵 / 上方向鍵 | 跳躍 |
| 頂撞／咬住物品 | J | 頂撞／咬 |
| 抓撓家具 | 按住 K | 按住抓撓 |
| 衝撞衝刺 | L 或 Shift | 衝撞 |
| 躲藏／離開藏身處 | E | 躲藏 |
| 嗅聞尋骨頭 | F | 聞香 |
| 暫停／返回 | Esc | 畫面右上暫停 |

手機介面依橫向、直向與螢幕高度調整，Canvas 使用等比例世界座標，避免角色被拉長。若裝置效能較弱，可以在設定關閉背景音樂或觸控按鈕（使用鍵盤時）。

## 技術架構

專案保持 **無建置工具、無外部 JS 框架、無第三方美術素材**，適合部署在 Cloudflare Pages：

- `index.html`：既有遊戲核心（Canvas 繪圖、物理、物件、主人 AI、音效、存檔）
- `chaos-expansion.js`：新增關卡、連續世界、重生與收集、委託、造型及存檔相容邏輯
- `chaos-expansion.css`：選單視覺、衣櫃、HUD、手機直向與橫向響應式樣式
- `README.md`：玩法、結構及部署說明

原有核心以 `window.ShibaChaosEngine` 提供擴充點，新功能保留在獨立模組，避免整個遊戲持續堆在單一 HTML。

### 存檔相容

仍使用 `wumetax_shibachaos_v1`，並保留對 `wumetax_catchaos_v1` 舊名稱的讀取。舊有的 1–3 關最高分、星級、解鎖技能及音效設定不會因新增關卡被清除。存檔僅在目前瀏覽器中保留，清除網站資料或手動重設存檔會失去進度。

## 本地預覽與部署

不需要 npm install、資料庫或 API Key；在專案根目錄啟動靜態伺服器即可：

```bash
python3 -m http.server 8000
```

開啟 `http://localhost:8000/` 即可。也可將 GitHub 主分支連結到 Cloudflare Pages，**建置指令留空、輸出目錄為專案根目錄**，透過靜態檔案部署。

## 回歸測試重點

1. 五關皆可進入、操作、達成目標與結算；第 3 關解鎖第 4 關，第 4 關解鎖第 5 關
2. 自由模式可以連續走到五間房，不會因時間或三次被抓而結束
3. 骨頭會拾取、計入錢包、暫時消失，稍後重新生成
4. 循環委託完成後發放骨頭，切換至下一個任務
5. 造型僅扣款一次，已購買的造型再次穿戴不扣骨頭
6. 手機直向／橫向按鈕可操作且遊戲畫面保持等比例
7. 舊版存檔可被讀取，進度不會消失

請勿將自己修改的遊戲內容、角色、美術或音效誤認為第三方授權素材。本專案現有柴犬與環境圖形主要由 Canvas 直接繪製，不依賴外部圖片載入。
